# 🚆 Online Reservation System

💻 A simple and user-friendly Train Reservation System built using **Java Swing**.

## ✨ Features

- 🔐 **Login Authentication** – Access the reservation system
- 🎫 **Ticket Booking** – Enter passenger and journey details
- 🔎 **PNR Lookup** – View reservation details using a unique PNR
- ❌ **Ticket Cancellation** – Cancel existing reservations
- 🖥️ **Interactive GUI** – Simple and user-friendly interface
- ✅ **Input Validation** – Validate booking details
- 📋 **Temporary Data Storage** – Manage reservations using ArrayList

## 🛠️ Technologies Used

- ☕ Java
- 🖼️ Java Swing
- 🧩 Object-Oriented Programming (OOP)
- 📦 ArrayList

## 🚀 How to Run

1. 📥 Clone or download this repository.
2. 💻 Open the project in IntelliJ IDEA.
3. ☕ Ensure the JDK is installed.
4. ▶️ Run `OnlineReservationSystem.java`.
5. 🔑 Use the default login credentials:

   - **Username:** `admin`
   - **Password:** `admin123`

## ⚠️ Note

📌 This version uses ArrayList for temporary data storage. All reservation data is lost when the application closes.
